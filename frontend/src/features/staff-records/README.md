Staff patients (ADR-043): teachers, non-teaching staff and utility workers seen at the clinic. Staff List, Staff Profile and Add/Edit Staff, School Clinician only; the Admin has no Staff item and is redirected from `/staff`. In code the entity is `Personnel` ("Staff" already names the clinician role); on screen it is Staff. Lists elsewhere show the Staff No., never the name (`cliniq-display-privacy`). See CLINIQ-Knowledge-Base/01-Requirements/Features/Module-Overview.md, section 2a.
