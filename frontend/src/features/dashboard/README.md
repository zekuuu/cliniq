Clinic Overview Dashboard — key operational totals, attention links, trends, and display-private frequent-visitor warnings. The Calendar lives in `CalendarPage.tsx` as its own Staff/Admin sidebar screen (ADR-032).

Dashboard has two views: **Overview** (visits, incidents, active students, pending excuse letters, due/overdue follow-ups, compact inventory/incomplete-record attention chips, then frequent visitors; Staff open pending letters from their stat card, which goes to the Visit Log at `?letter=pending`) and **Trends** (complaint trends). The shared `Tabs` keeps Trends in `?view=trends` with replace navigation. Legacy `?view=calendar` links replace to `/calendar`. The Overview tab badge counts follow-up, inventory, and incomplete-record attention. Staff can create a visit from the tab row. When a backup has failed, is missing, or needs verification, the desktop Backup navigation item shows a warning icon.

Trends: a one-day range (Today, or a one-day Custom range) plots hourly. A calendar-month range groups visits and incidents Monday to Sunday beside the equivalent previous month; grouped bars use solid versus outlined datasets, and the Chart/Table control provides the full text alternative with busiest date and known event/holiday context. Other ranges keep their date-derived buckets. The complaint-trend table sorts by Complaint and Total only, not by period.

Print produces the "Clinic Overview Report" (`components/DashboardPrint.tsx`, ADR-026): a one-to-two-page A4 summary of the Date range from the data the page already loaded. It does not print calendar events or holidays, and Calendar has no print action.
