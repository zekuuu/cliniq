Clinic Visit Monitoring — daily visit logging, excuse letters, PE/Sports referrals, and Follow-Up Handling (shared with emergency-response). See Modules & Features canonical doc.

The Excuse Letter prints as an A4 letter with letterhead, signature block, and a reference block; only an approved, superseded or void letter prints (the last two stamped SUPERSEDED or VOID); a draft stays on screen with Print disabled ("Approve the letter to print it.", ADR-038 item 6).

The visit also takes five optional fields from the clinic's daily logbook (body temperature, time out, assisted by, parent/guardian, remarks), in a collapsed "Show more fields" section on New Visit and the edit form (`LogbookFields.tsx`, values in `logbookValues.ts`). Visit Detail shows the filled ones (Time out with the visit's date); the Visit Log table and printed pages don't show them. "Assisted by" is a `Combobox` of active account names that accepts free text (`fetchAssistedByNames`); New Visit prefills Parent or guardian from the primary emergency contact when it is empty (Sir Rey, Sunday, October 25, 2026).
