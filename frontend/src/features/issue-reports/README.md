# Report an Issue

## What it is
A form for reporting a problem with CLINIQ to the development team.

## Screens and who can use them
- Report an Issue (a dialog opened from the sidebar footer): both roles.

## Rules that matter
- Submitting saves the report and opens an email to the address in `reportIssueConfig.ts`; the user sends it from their own mail program.

## Data and API files
`api/issueReportApi.ts`, `reportIssueConfig.ts`.

## Printouts and tests
No printout. Tests: `ReportIssueModal.test.tsx`, `api/issueReportApi.test.ts`.
