Shell/wrapper layouts — `AppShell` (role-aware `Sidebar` from `navigation.ts` plus the top bar; below `lg`, a menu button opens the same navigation, ADR-022). For Staff the top bar carries `TopBarSearch` (from the `xl` width; "/" focuses it): one box that finds a student or staff member through `usePatientSearch` and opens the profile (ADR-086). Every signed-in screen renders inside it (`routes/AppRoutes.tsx`). Back is not part of the shell: each screen places the shared `BackButton` itself (ADR-024).
