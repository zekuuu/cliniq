Changes Made:
- **Combobox** (generic over the option type): input with `role="combobox"`, `aria-expanded`, `aria-controls`, `aria-activedescendant`; `role="listbox"` / `role="option"` panel. Down/Up open and move, Enter picks the highlighted option and never submits the form, Escape closes (or clears when closed), Tab moves on. The field uses `dropdownTriggerClassName` (40px, semibold) with a text cursor and the brand chevron; the panel uses `DROPDOWN_PANEL` and `placeDropdownPanel`. Props: `allowFreeText`, `autoHighlight`, `openOnFocus`, `loading`, `loadError`, `noMatchesText` (`null` keeps the panel closed). The caller filters and caps the options.
- **Complaint:** new selector `complaintSuggestions(state)` merges the predefined visit complaint types with every saved visit complaint, case-insensitively (a predefined type keeps its spelling, otherwise the latest spelling). Ranking: visit count, then most recent use, then alphabetical (never-used predefined types last). Exposed as `getVisitComplaintSuggestions()` and loaded with the New Visit context; refreshed after a save. `lib/complaints.ts` holds `cleanComplaint` (trim, collapse whitespace, 60 characters) and `normalizeComplaint` (adopt a matching suggestion's spelling). The page normalizes on save, and `recordVisit` normalizes again in the data layer. Smart Triage matches the cleaned text case-insensitively; ticked steps survive edits that keep the same matched type. Validation: "Enter the complaint for this visit." Helper: "The complaint or symptom only. Don't include names." The field stops at 60 characters.
- **StudentPicker:** a Combobox without free text. Data layer `searchStudents(query, limit = 8)` via selector `searchStudents`: active students, Student Number prefix or name substring, case-insensitive, nothing under 2 characters (`STUDENT_SEARCH_MIN_LENGTH`), number matches first then by name, returning only `StudentSearchResult` (id, Student Number, full name, grade). Each option shows Student Number, bold full name, and grade. A complete Student Number auto-highlights its match, so Enter picks it. Stale results are hidden while a new search loads, so Enter can't pick an old result. "No active student matches “…”." appears under the field, with an "Add a student" link (`paths.studentNew`) when the viewer is Staff.
- **New Visit:** without `?student=`, it shows the StudentPicker. A pick loads the full student through `useIdentifiedStudent.select()` (new), which also brings the allergies beside the medicine picker. The form then shows the student (name · number · grade) with a Change button that returns focus to the search. `useIdentifiedStudent.validate()` takes an optional message ("Choose the student: …"). With `?student=`, nothing changes: no picker, and the name is in the header. The typed-number allergy pre-lookup was removed; the pick replaces it.
- **Skill:** created `cliniq-combobox-patterns` (no combobox skill existed; `cliniq-item-picker-patterns` covers the inventory picker only, and `InventoryItemPicker` was left as is). It records only what this request specified.
Reason: Complaints that didn't fit the fixed list had nowhere to go, and staff could only identify an unscanned student by typing the full Student Number.
