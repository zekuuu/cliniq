## For the backend branch

Copy these exactly; they are what the frontend now does.

- **Fields (students and personnel alike):** `firstName` (required), `lastName` (required), `middleName` (optional; `null` when none, never an empty string). Suggested columns: `first_name varchar(50) NOT NULL`, `last_name varchar(50) NOT NULL`, `middle_name varchar(40) NULL`, each trimmed, single-spaced and non-blank when present (`char_length(trim(x)) >= 1`). Together with two spaces they fit the former `full_name varchar(150)`.
- **Limits:** first name 50, middle name 40, last name 50 characters (`NAME_PART_MAX` in `frontend/src/lib/personName.ts`).
- **Derived full name:** never stored. `formatPersonName` = the non-empty parts joined by one space in the order First, Middle, Last: "Maria Angela Santos Dela Cruz"; without a middle name "Ana Reyes". The API returns `fullName` built this way wherever it returned it before (list rows keep `fullName` only; API contract Q2 is unchanged).
- **Validation messages:** "Enter the student's first name." / "Enter the student's last name." (staff: "Enter the staff member's first name." / "…last name."); "The first name can be at most 50 characters." (and middle 40, last 50).
- **Search:** every whitespace-separated word of the query must appear somewhere in the full name, case-, accent- and space-insensitive ("dela cruz", "maria santos", "cruz maria" all find "Maria Angela Santos Dela Cruz"). LRN and Staff No. prefix search are unchanged.
- **Sort:** last name, then first name, then middle name (`localeCompare`), for the Student List, Staff List, Incomplete Records queue, import "not in this file" list, patient search and Sports Report.
- **Duplicates:** compare the full names after trimming, collapsing spaces, removing accents (NFD) and lowercasing; the collation already gives accent- and case-insensitivity.
- **Audit wording:** a changed name part is named by field only: "Updated first name", "Updated last name", "Updated middle name" (joined like other fields: "Updated first name and last name"). A student name correction adds ". Name corrected; reason: <reason>" (ADR-058, as amended by ADR-064). Values never appear.
- **Import:** separate columns map to First name, Last name and Middle name. A single "Full name (one column)" column is accepted when no First or Last column is matched. Rule: with a comma, "Surname, First Middle": the last name is before the comma, and of the words after it the last is the middle name when there are two or more (one word is the first name, no middle). Without a comma, the last word is the last name and the rest is the first name, no middle. The preview lists every split (row, last, first, middle).
- **Existing data:** the seed had only two-word names (first word first, second word last, middle null). ERD open decision D-15 is settled by ADR-064.
