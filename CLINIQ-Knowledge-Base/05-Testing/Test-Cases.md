# Test Cases

No separate test-case list is kept. The tests live beside the code; their current counts and the last recorded results are in the [Facts sheet](../00-Project-Core/Facts-Sheet.md#test-runs) (Tuesday, November 10, 2026: frontend 135 Vitest files, 1185 tests; backend 8 Pest files, 85 tests). Run them with `npm test` in `frontend/` and `composer test` in `backend/`. Requirement-to-test links are in the [traceability table](../01-Requirements/Functional-Requirements.md#traceability); the database's 260 constraint test cases are in `02-Architecture/Database/Checks/`. Audited actions and their tests are in `04-Development/Audit-Coverage.md`. Backend test cases come with the backend (`04-Development/Backend-Loop-Engineering.md`).
