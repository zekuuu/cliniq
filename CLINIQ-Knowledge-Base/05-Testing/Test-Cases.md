# Test Cases

No separate test-case list is kept. The tests live beside the code; their current counts and the last recorded results are in the [Facts sheet](../00-Project-Core/Facts-Sheet.md#test-runs) (Sunday, November 15, 2026: frontend 135 Vitest files, 1185 tests; backend 25 Pest files, 228 tests; database parity and 260 of 260 constraint tests). Run them with `npm test` in `frontend/`, and `composer test` and `php tools/db-checks.php` in `backend/`. Requirement-to-test links are in the [traceability table](../01-Requirements/Functional-Requirements.md#traceability); the database's 260 constraint test cases are in `02-Architecture/Database/Checks/`. Audited actions and their tests are in `04-Development/Audit-Coverage.md`. Backend test cases are named in each phase's build and audit notes in `04-Development/Backend-Loop-Engineering.md`.
